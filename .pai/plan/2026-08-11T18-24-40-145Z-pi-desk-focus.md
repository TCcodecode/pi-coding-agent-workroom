# PI Desk 视觉统一:状态点颜色体系 + focus 样式

## 目标

统一 PI Desk 各处会话状态指示的颜色语义,并消除 focus/选中态中的粗灰描边,让界面更干净、状态更可读。

## 背景 / 现状

本次会话开始时状态颜色不一致:

- 会话状态点只有 running / waiting / error 三色,completed 无独立颜色
- Inspector 顶部 `status-dot` 用了另一套颜色(琥珀 running、蓝 awaiting、另一种绿)
- focus 态统一走 `--focus-ring: 0 0 0 2px rgba(32,32,32,.18)`,视觉上是粗灰描边,对话框内尤其明显
- checkbox 使用浏览器默认 outline(灰色粗边)

## 已完成的改动

### 1. 会话状态点颜色体系(统一色值)

| 状态 | 色值 | 含义 |
|---|---|---|
| running(执行中) | `#4D6787` 灰蓝 | 进行中 |
| awaiting_approval(等待) | `#e4b961` 黄 | 等待输入/审批 |
| completed(已完成) | `#7DCCAD` 绿 | 完成 |
| error(错误) | `#e8a09a` 红 | 失败 |
| 无状态 | 不渲染点 | 无明确状态不显示 |

应用位置(三处全部统一):
- 顶部 Tab:`session-tab-dot`(SessionTabBar.tsx)
- 左侧侧边栏:`session-dot`(SessionSidebar.tsx)
- Inspector 顶部:`status-dot`(ResourceInspector.tsx)

关键修复:
- `completed` 状态此前无映射,已加入 `statusClass()` / `sessionStatusClass()`,并新增 `is-completed` 样式
- 侧边栏 `.session-item.nested.active .session-dot` 优先级更高会覆盖状态色,已加 `:not(状态类)` 限定,状态色优先生效
- `idle` 与 `completed` 拆分:idle 中性灰、completed 绿色
- light/dark 主题都覆盖了统一色值

### 2. Focus / 选中态样式

- `--focus-ring`(深色):`0 0 0 2px rgba(32,32,32,.18)` → `0 0 0 1px rgba(255,255,255,.12), 0 4px 16px rgba(0,0,0,.32)`(1px 细线 + 深阴影)
- light 主题新增 `--focus-ring` 覆盖:同思路,浅色下细线 + 柔和阴影
- checkbox:全局 `outline: 0`,focus-visible 改用柔和阴影
- HTTP 对话框输入框 focus:`2px` ring → `0 1px 8px` 阴影

## 风险 / 注意

- `--focus-ring` 是全局变量,所有用到它的控件(按钮、select、ctrl-box、composer 卡片)focus 视觉都会变化,已属预期;如个别控件需要更强/更弱反馈,需单独覆盖
- `:not()` 限定的 active 默认色规则已删除(无状态不再渲染点),若未来恢复「无状态显示灰点」需要重新加回
